## 怎样使用

1. 在“指南”按生活主题进入，或搜索一个具体问题。
2. “全部”可组合主题、章节、“钱标签为0”和作者证据分级筛选。钱标签是原作者分类，不承诺全过程免费。
3. 详情按原书顺序显示成本、解读、收益、证据等级、来源、备注，可直接跳到备注查看条件与争议；正文可选择复制。
4. 点击“收藏这条建议”，以后在“收藏”中查找。最近 100 条阅读记录也保存在这里，可单独清空。
5. 在详情展开“来源·原文”，复制链接到浏览器查看；也可复制直接定位本条行号的原文链接。本版不承诺在微信内直接打开任意外部网站。

收藏与阅读记录仅保存在当前设备。没有自建账号、后台、支付、云同步或外部 AI 请求。清理缓存、删除小程序或换设备可能丢失记录。格式损坏时保留原数据，不自动覆盖或重置。

## 维护与验收

内容构建器：`python scripts/build-content.py --source-root <固定版本的上游解压目录>`。每次更新必须检查构建报告、来源链接、争议文字、主包及内容分包体积；原作者条目编号可能变化，不应只按新编号覆盖旧收藏。

独立测试：`npm test`。微信测试使用 `miniprogram-automator@0.12.1`，先在官方工具开启项目自动化，再设置 `WX_AUTOMATION_ENDPOINT` 运行 `npm run test:wechat`。此依赖只用于开发，不进小程序代码包。

首版最小验证是“能找到一条建议、读懂条件、保存并重新找到”。本次不自动启动收费、内容营销或运营排期，既有星图经营主线不变。
